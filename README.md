# Sympy – regning med symboler

Lær å bruke sympy til det du har brukt CAS i GeoGebra til: forenkle, faktorisere og løse likninger og likningssett, med eksakte svar.

Åpne [`oppgave.ipynb`](./oppgave.ipynb) i Codespaces (knappen "Code" → "Codespaces" øverst på denne siden) eller i VS Code for å komme i gang.

Denne oppgaven har automatisk retting. Kjør "Test løsningen din"-cellen nederst i notebooken når som helst for umiddelbar tilbakemelding. Den samme sjekken kjøres automatisk når du leverer inn.
